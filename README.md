## ⚡ About Me

I'm a **Computer Science Engineering (AI & ML)** student and developer who loves building fast, local-first software that solves practical problems. Whether I'm training real-time computer vision models, shipping multi-module Android apps with Google Sheets sync, or writing custom Minecraft Fabric client mods and launchers, I focus on clean architecture and tools that run smoothly on consumer hardware.

- 🔭 **Currently working on:** Local AI video clipping pipelines (`Ai Cutter` & custom stream highlight models) and **Omega Litematica** for Fabric 1.21.11.
- 🧠 **Core focus areas:** Computer Vision & Local LLM Workflows, Automated Media Processing, Android Development (Kotlin), and Minecraft Modding (Java/Rust/Tauri).
- ⚡ **Philosophy:** Air-gapped & local-first where possible—minimal cloud bloat, maximum performance.
